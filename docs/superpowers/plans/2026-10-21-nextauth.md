# NextAuth (Auth.js v5) sobre API propia — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dar sesión real al frontend (`frontend/`) con Auth.js v5 (NextAuth), envolviendo la API NestJS ya existente (credentials + Google), sin duplicar la lógica de sesión del backend.

**Architecture:** Estrategia JWT de NextAuth (sin adapter de DB) usada como caché server-side de los tokens que ya emite el backend (`accessToken` 15 min + `refreshToken` opaco rotativo 30 días). `CredentialsProvider` llama `POST /auth/login`; `GoogleProvider` solo hace la danza OAuth con Google para obtener un `id_token`, que se intercambia por `POST /auth/google`. El callback `jwt` refresca proactivamente antes de que expire el access token; `proxy.ts` (Next 16) protege `/admin` y `/cuenta` leyendo la sesión con el helper `auth()`.

**Tech Stack:** Next.js 16 (App Router, `frontend/`), `next-auth@5` (beta/Auth.js v5), TypeScript strict, Vitest (unitarias), Playwright (e2e contra backend real).

**Spec:** `docs/superpowers/specs/2026-10-21-nextauth-design.md`

## Global Constraints

- Backend es la única fuente de verdad de sesión: no se agrega adapter de base de datos a NextAuth (D46, D56).
- `refreshToken` del backend **nunca** se expone al cliente — el callback `session` de NextAuth solo expone `accessToken` + `user` + `error?`.
- `AUTH_GOOGLE_ID` del frontend debe ser el **mismo** valor que `GOOGLE_CLIENT_ID` del backend (mismo client OAuth de Google) — el backend verifica el `aud` del `id_token` contra ese client ID (D53).
- `API_URL` del frontend apunta al backend en `http://localhost:3000` (D60: API puerto 3000, web puerto 3001).
- Next.js 16: el archivo se llama `proxy.ts` (no `middleware.ts`); `params`/`searchParams` de las páginas son `Promise`.
- Shape de respuesta del backend, fijo (no se cambia en este plan): `{accessToken: string, refreshToken: string, user: {id, email, name, role, phone, emailVerifiedAt}}` (`backend/src/auth/dto/auth-response.dto.ts`).
- `Role` del backend es `'CUSTOMER' | 'ADMIN'` (`backend/src/database/enums.ts`).
- Identificadores y código en inglés; copy de UI visible al usuario en español (CLAUDE.md del proyecto).
- Commits nuevos (no `--amend`), sin línea `Co-Authored-By`, sin `--no-verify` (CLAUDE.md del proyecto).

```typescript
// frontend/src/lib/jwt-exp.ts

/** Decodifica (sin verificar firma) el campo `exp` de un JWT y lo devuelve en epoch ms. */
export function decodeJwtExpiry(jwt: string): number {
  const payload = jwt.split(".")[1];
  if (!payload) {
    throw new Error("Token JWT inválido: falta el payload");
  }
  const json = Buffer.from(payload, "base64url").toString("utf8");
  const parsed = JSON.parse(json) as { exp?: number };
  if (!parsed.exp) {
    throw new Error("Token JWT sin campo exp");
  }
  return parsed.exp * 1000;
}
```

```typescript
// frontend/src/lib/api-client.ts

export interface BackendUser {
  id: string;
  email: string;
  name: string | null;
  role: "CUSTOMER" | "ADMIN";
  phone: string | null;
  emailVerifiedAt: string | null;
}

export interface BackendTokenPair {
  accessToken: string;
  refreshToken: string;
}

export interface BackendAuthResult extends BackendTokenPair {
  id: string;
  user: BackendUser;
}

const API_URL = process.env.API_URL ?? "http://localhost:3000";

interface BackendAuthPayload {
  accessToken: string;
  refreshToken: string;
  user: BackendUser;
}

async function postJson<T>(
  path: string,
  body: unknown,
  accessToken?: string,
): Promise<{ ok: true; data: T } | { ok: false; status: number }> {
  const res = await fetch(`${API_URL}${path}`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      ...(accessToken ? { Authorization: `Bearer ${accessToken}` } : {}),
    },
    body: JSON.stringify(body),
    cache: "no-store",
  });
  if (!res.ok) {
    return { ok: false, status: res.status };
  }
  const data = res.status === 204 ? (undefined as T) : ((await res.json()) as T);
  return { ok: true, data };
}

export async function login(email: string, password: string): Promise<BackendAuthResult | null> {
  const result = await postJson<BackendAuthPayload>("/auth/login", { email, password });
  if (!result.ok) {
    return null;
  }
  return { id: result.data.user.id, ...result.data };
}
```

```typescript
// frontend/src/auth.ts
import NextAuth from "next-auth";
import Credentials from "next-auth/providers/credentials";
import { login } from "@/lib/api-client";
import { decodeJwtExpiry } from "@/lib/jwt-exp";

export const { handlers, auth, signIn, signOut } = NextAuth({
  trustHost: true,
  secret: process.env.AUTH_SECRET,
  session: { strategy: "jwt" },
  pages: { signIn: "/login" },
  providers: [
    Credentials({
      credentials: { email: {}, password: {} },
      authorize: async (credentials) => {
        const email = credentials?.email;
        const password = credentials?.password;
        if (typeof email !== "string" || typeof password !== "string") {
          return null;
        }
        return login(email, password);
      },
    }),
  ],
  callbacks: {
    async jwt({ token, user }) {
      if (user) {
        token.accessToken = user.accessToken;
        token.refreshToken = user.refreshToken;
        token.accessTokenExpiresAt = user.accessToken ? decodeJwtExpiry(user.accessToken) : undefined;
        token.user = user.user;
        delete token.error;
        return token;
      }
      return token;
    },
    async session({ session, token }) {
      if (token.user) {
        session.user = token.user as typeof session.user;
      }
      session.accessToken = token.accessToken ?? "";
      if (token.error) {
        session.error = token.error;
      }
      return session;
    },
  },
});
```

```typescript
import { refreshTokens } from "./api-client";
import { decodeJwtExpiry } from "./jwt-exp";

export const DEFAULT_REFRESH_BUFFER_MS = 60_000;

export function needsRefresh(
  accessTokenExpiresAt: number | undefined,
  now: number,
  bufferMs: number = DEFAULT_REFRESH_BUFFER_MS,
): boolean {
  if (!accessTokenExpiresAt) {
    return false;
  }
  return now > accessTokenExpiresAt - bufferMs;
}

export interface RefreshableToken {
  accessToken?: string;
  refreshToken?: string;
  accessTokenExpiresAt?: number;
  error?: string;
}

export async function applyRefreshIfNeeded<T extends RefreshableToken>(
  token: T,
  now: number = Date.now(),
): Promise<T> {
  if (!token.refreshToken || !needsRefresh(token.accessTokenExpiresAt, now)) {
    return token;
  }
  const refreshed = await refreshTokens(token.refreshToken);
  if (!refreshed) {
    return { ...token, error: "RefreshError" } as T;
  }
  return {
    ...token,
    accessToken: refreshed.accessToken,
    refreshToken: refreshed.refreshToken,
    accessTokenExpiresAt: decodeJwtExpiry(refreshed.accessToken),
    error: undefined,
  } as T;
}
```

`as T`: TypeScript no permite devolver un objeto literal (aunque sea `{...token, ...}`) como el tipo genérico `T` sin cast explícito — es una limitación conocida de genéricos, no un `any` real, porque `T extends RefreshableToken` ya garantiza la forma mínima.

```typescript

import { NextResponse } from "next/server";
import { auth } from "@/auth";

const ADMIN_PREFIX = "/admin";
const PROTECTED_PREFIXES = ["/cuenta", ADMIN_PREFIX];

export default auth((req) => {
  const { pathname } = req.nextUrl;
  const isProtected = PROTECTED_PREFIXES.some((prefix) => pathname.startsWith(prefix));
  if (!isProtected) {
    return NextResponse.next();
  }

  const session = req.auth;
  if (!session || session.error) {
    const loginUrl = new URL("/login", req.url);
    loginUrl.searchParams.set("callbackUrl", pathname);
    return NextResponse.redirect(loginUrl);
  }

  if (pathname.startsWith(ADMIN_PREFIX) && session.user.role !== "ADMIN") {
    return NextResponse.redirect(new URL("/", req.url));
  }

  return NextResponse.next();
});

export const config = {
  matcher: ["/admin/:path*", "/cuenta/:path*"],
};
```
