# Reclamos y reposición de licencia (S8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the claims/replacement module (S8, roadmap step 7) end to end: a customer can report an
invalid key on a delivered order and get a replacement license or a clear rejection; an admin resolves the
queue from `/admin/reclamos`.

**Architecture:** New backend module `src/claims/` (customer `/claims` + admin `/admin/claims`), two new
Postgres functions (`fn_resolve_claim`, `fn_reject_claim`) for the atomic replace/reject transaction, and a
small additive DTO change (`orderItemId` on order items) so the customer can target a specific license. On the
frontend, extend the existing `/pedidos` screen (built in S4) with a "Reportar un problema" flow, and replace
the `/admin/reclamos` placeholder with a master-detail queue copied structurally from `/admin/pagos`.

**Tech Stack:** NestJS (TypeORM `DataSource.query` raw SQL + a Postgres migration with `plpgsql` functions),
class-validator DTOs, Next.js Server Actions (`"use server"` lib files), React client components, Vitest,
Jest + Supertest e2e against real Postgres/Redis.

**Spec:** `docs/superpowers/specs/2026-11-13-reclamos-s8-design.md`

## Global Constraints

- Alcance solo prioridad M: RF-REC-01..05 + RF-ADM-30..32 + auditoría. RF-REC-06 (reembolso) y RF-NOT-05
  (correo) quedan explícitamente fuera.
- D25: ventana de reposición = 7 días desde la entrega. Se usa `orders."updatedAt"` como proxy de "entregado el"
  (no existe columna `deliveredAt`; una vez `DELIVERED` nada más toca esa fila).
- D26: máximo 1 reposición por pedido. Bloquea crear un reclamo nuevo si ya existe uno `OPEN` o `RESOLVED` para
  ese pedido. Un reclamo `REJECTED` **no** bloquea un reclamo nuevo (rechazar no es "usar la reposición").
- D28: al resolver, la licencia original pasa a `VOID` **conservando su `orderItemId` histórico** (no se pone
  en `NULL`); la licencia de reemplazo toma ese mismo `orderItemId` y `status = 'SOLD'`, con `replacesId`
  apuntando a la original.
- El admin **nunca** descifra/revela la clave reclamada — se muestra siempre enmascarada en `GET /admin/claims`.
- `POST /admin/claims/:id/reject` usa motivo **de texto libre**, no un catálogo fijo de motivos.
- D57: la transacción de resolver/rechazar vive en funciones Postgres (`fn_resolve_claim`/`fn_reject_claim`),
  mismo patrón que `fn_approve_payment`/`fn_reject_payment`. La creación de un reclamo (una sola inserción con
  checks previos) se valida en TypeScript dentro de una transacción con `SELECT ... FOR UPDATE` sobre el
  pedido — no necesita una función SQL dedicada.
- `AllExceptionsFilter` (`backend/src/common/filters/all-exceptions.filter.ts`) ya traduce cualquier
  `RAISE EXCEPTION ... USING ERRCODE = 'P0001'` a `409` con un mensaje **genérico** ("Operación no permitida en
  el estado actual") — nunca propaga el texto del `RAISE EXCEPTION` al cliente. Por eso los mensajes
  específicos (ventana vencida, reclamo ya abierto, etc.) se lanzan como `ConflictException` en TypeScript, no
  vía `RAISE EXCEPTION`.
- Nunca usar `--no-verify`. Commits nuevos, no `--amend`. Sin coautor en los commits (autor único: Alfredo).
- Flujos con estado/stock/dinero requieren prueba e2e contra Postgres/Redis reales (regla del proyecto) — no
  hay tests unitarios de servicios en este backend, solo e2e + los pocos unit de infraestructura ya existentes.
- Entidades/rutas/código en inglés; mensajes al usuario y comentarios en español.

```typescript
import type { MigrationInterface, QueryRunner } from 'typeorm';

/**
 * Resolver/rechazar un reclamo como transacción atómica en Postgres (D57, mismo patrón que
 * fn_approve_payment/fn_reject_payment de AdminPaymentFunctions): el servicio nunca arma estos
 * pasos a mano, así que un bug en NestJS no puede dejar la licencia original y el reemplazo
 * activos a la vez.
 */
export class ClaimFunctions<TS> implements MigrationInterface {
  name = 'ClaimFunctions<TS>';

  public async up(queryRunner: QueryRunner): Promise<void> {
    await queryRunner.query(
      `ALTER TABLE claims ADD COLUMN "rejectionReason" text NULL`,
    );

    await queryRunner.query(`
      CREATE OR REPLACE FUNCTION fn_resolve_claim(p_claim_id uuid, p_admin_id uuid)
      RETURNS text LANGUAGE plpgsql AS $$
      DECLARE
        v_claim claims%ROWTYPE;
        v_plan_id uuid;
        v_order_item_id uuid;
        v_replacement_id uuid;
      BEGIN
        SELECT * INTO v_claim FROM claims WHERE id = p_claim_id FOR UPDATE;
        IF NOT FOUND THEN
          RETURN NULL;
        END IF;
        IF v_claim.status <> 'OPEN' THEN
          RAISE EXCEPTION 'El reclamo ya fue resuelto' USING ERRCODE = 'P0001';
        END IF;

        SELECT "planId", "orderItemId" INTO v_plan_id, v_order_item_id
          FROM license_items WHERE id = v_claim."licenseItemId";

        SELECT id INTO v_replacement_id FROM license_items
         WHERE "planId" = v_plan_id AND status = 'AVAILABLE'
         ORDER BY "createdAt"
         LIMIT 1
         FOR UPDATE SKIP LOCKED;

        IF v_replacement_id IS NULL THEN
          RETURN 'NO_STOCK';
        END IF;

        UPDATE license_items SET status = 'VOID'
         WHERE id = v_claim."licenseItemId";

        UPDATE license_items
           SET status = 'SOLD', "soldAt" = now(),
               "orderItemId" = v_order_item_id, "replacesId" = v_claim."licenseItemId"
         WHERE id = v_replacement_id;

        UPDATE claims
           SET status = 'RESOLVED', "replacementLicenseId" = v_replacement_id,
               "resolvedById" = p_admin_id, "resolvedAt" = now()
         WHERE id = p_claim_id;

        RETURN 'RESOLVED';
      END $$;
    `);

    await queryRunner.query(`
      CREATE OR REPLACE FUNCTION fn_reject_claim(p_claim_id uuid, p_admin_id uuid, p_reason text)
      RETURNS boolean LANGUAGE plpgsql AS $$
      DECLARE
        v_status text;
      BEGIN
        SELECT status INTO v_status FROM claims WHERE id = p_claim_id FOR UPDATE;
        IF NOT FOUND THEN
          RETURN false;
        END IF;
        IF v_status <> 'OPEN' THEN
          RAISE EXCEPTION 'El reclamo ya fue resuelto' USING ERRCODE = 'P0001';
        END IF;

        UPDATE claims
           SET status = 'REJECTED', "rejectionReason" = p_reason,
               "resolvedById" = p_admin_id, "resolvedAt" = now()
         WHERE id = p_claim_id;

        RETURN true;
      END $$;
    `);
  }

  public async down(queryRunner: QueryRunner): Promise<void> {
    await queryRunner.query(`DROP FUNCTION IF EXISTS fn_reject_claim(uuid, uuid, text)`);
    await queryRunner.query(`DROP FUNCTION IF EXISTS fn_resolve_claim(uuid, uuid)`);
    await queryRunner.query(`ALTER TABLE claims DROP COLUMN IF EXISTS "rejectionReason"`);
  }
}
```

- [ ] **Step 4: Service**

Crea `backend/src/claims/claims.service.ts`:

```typescript
import { ConflictException, Injectable, NotFoundException } from '@nestjs/common';
import { DataSource } from 'typeorm';
import { AuditService } from '../audit/audit.service';
import { PaginatedResponseDto } from '../common/dto/paginated-response.dto';
import type { PaginationQueryDto } from '../common/dto/pagination-query.dto';
import type { AuthenticatedUser } from '../common/types/authenticated-user';
import { ClaimStatus, OrderStatus } from '../database/enums';
import { CLAIM_WINDOW_DAYS } from './claims.constants';
import { ClaimResponseDto, type ClaimRow } from './dto/claim-response.dto';
import { CreateClaimDto } from './dto/create-claim.dto';

interface OrderRow {
  id: string;
  status: OrderStatus;
  updatedAt: Date;
  orderNumber: number;
}

@Injectable()
export class ClaimsService {
  constructor(
    private readonly ds: DataSource,
    private readonly audit: AuditService,
  ) {}

  /** RF-REC-01..03/05: una sola inserción con checks previos, serializada por el lock del pedido. */
  async create(
    user: AuthenticatedUser,
    dto: CreateClaimDto,
  ): Promise<ClaimResponseDto> {
    return this.ds.transaction(async (m) => {
      const orders: OrderRow[] = await m.query(
        `SELECT id, status, "updatedAt", "orderNumber" FROM orders
          WHERE id = $1 AND "userId" = $2 FOR UPDATE`,
        [dto.orderId, user.id],
      );
      const order = orders[0];
      if (!order) {
        throw new NotFoundException('Pedido no encontrado');
      }
      if (order.status !== OrderStatus.DELIVERED) {
        throw new ConflictException('Solo puedes reclamar un pedido entregado');
      }

      const windowEndMs =
        new Date(order.updatedAt).getTime() + CLAIM_WINDOW_DAYS * 24 * 60 * 60_000;
      if (Date.now() > windowEndMs) {
        throw new ConflictException('La ventana de reposición de 7 días ya venció');
      }

      const existing: { status: ClaimStatus }[] = await m.query(
        `SELECT status FROM claims WHERE "orderId" = $1`,
        [dto.orderId],
      );
      if (existing.some((c) => c.status === ClaimStatus.OPEN)) {
        throw new ConflictException('Ya tienes un reclamo abierto para este pedido');
      }
      if (existing.some((c) => c.status === ClaimStatus.RESOLVED)) {
        throw new ConflictException('Este pedido ya usó su reposición');
      }

      const licenses: { id: string }[] = await m.query(
        `SELECT li.id FROM license_items li
           JOIN order_items oi ON oi.id = li."orderItemId"
          WHERE oi.id = $1 AND oi."orderId" = $2 AND li.status = 'SOLD'`,
        [dto.orderItemId, dto.orderId],
      );
      const license = licenses[0];
      if (!license) {
        throw new NotFoundException('La licencia indicada no corresponde a este pedido');
      }

      const [{ id: claimId, createdAt }]: { id: string; createdAt: Date }[] =
        await m.query(
          `INSERT INTO claims ("orderId", "licenseItemId", "userId", reason)
           VALUES ($1, $2, $3, $4) RETURNING id, "createdAt"`,
          [dto.orderId, license.id, user.id, dto.reason],
        );

      await this.audit.log(m, {
        actorId: user.id,
        action: 'claim.created',
        entity: 'claim',
        entityId: claimId,
        meta: { orderId: dto.orderId },
      });

      return ClaimResponseDto.from({
        id: claimId,
        orderId: dto.orderId,
        orderNumber: order.orderNumber,
        status: ClaimStatus.OPEN,
        reason: dto.reason,
        rejectionReason: null,
        createdAt,
        resolvedAt: null,
      });
    });
  }

  /** RF-REC-04: "mis reclamos". */
  async listForUser(
    userId: string,
    dto: PaginationQueryDto,
  ): Promise<PaginatedResponseDto<ClaimResponseDto>> {
    const offset = (dto.page - 1) * dto.pageSize;
    const rows: ClaimRow[] = await this.ds.query(
      `SELECT c.id, c."orderId", o."orderNumber", c.status, c.reason,
              c."rejectionReason", c."createdAt", c."resolvedAt"
         FROM claims c
         JOIN orders o ON o.id = c."orderId"
        WHERE c."userId" = $1
        ORDER BY c."createdAt" DESC
        LIMIT $2 OFFSET $3`,
      [userId, dto.pageSize, offset],
    );
    const [{ count }]: { count: string }[] = await this.ds.query(
      `SELECT count(*) FROM claims WHERE "userId" = $1`,
      [userId],
    );
    const items = rows.map((row) => ClaimResponseDto.from(row));
    return PaginatedResponseDto.from(items, Number(count), dto.page, dto.pageSize);
  }
}
```

import { Body, Controller, Get, Post, Query } from '@nestjs/common';
import { ApiBearerAuth, ApiTags } from '@nestjs/swagger';

import { ConflictException, Injectable, NotFoundException } from '@nestjs/common';
import { DataSource } from 'typeorm';
import { AuditService } from '../audit/audit.service';
import { PaginatedResponseDto } from '../common/dto/paginated-response.dto';
import type { AuthenticatedUser } from '../common/types/authenticated-user';
import { ClaimStatus } from '../database/enums';
import { AdminClaimActionResponseDto } from './dto/admin-claim-action-response.dto';
import { AdminClaimResponseDto, type AdminClaimRow } from './dto/admin-claim-response.dto';
import { ListAdminClaimsQueryDto } from './dto/list-admin-claims-query.dto';
import { RejectClaimDto } from './dto/reject-claim.dto';

@Injectable()
export class AdminClaimsService {
  constructor(
    private readonly ds: DataSource,
    private readonly audit: AuditService,
  ) {}

  /** RF-ADM-30: cola con motivo, producto/plan y stock para reponer. Nunca la clave. */
  async list(
    dto: ListAdminClaimsQueryDto,
  ): Promise<PaginatedResponseDto<AdminClaimResponseDto>> {
    const offset = (dto.page - 1) * dto.pageSize;
    const rows: AdminClaimRow[] = await this.ds.query(
      `SELECT c.id AS "claimId", c."orderId", o."orderNumber", c.status, c.reason, c."createdAt",
              li."planId", pl.name AS "planName", pr.name AS "productName",
              u.name AS "customerName", u.email AS "customerEmail"
         FROM claims c
         JOIN orders o ON o.id = c."orderId"
         JOIN users u ON u.id = c."userId"
         JOIN license_items li ON li.id = c."licenseItemId"
         JOIN plans pl ON pl.id = li."planId"
         JOIN products pr ON pr.id = pl."productId"
        WHERE ($1::text IS NULL OR c.status::text = $1)
        ORDER BY c."createdAt" ASC
        LIMIT $2 OFFSET $3`,
      [dto.status ?? null, dto.pageSize, offset],
    );
    const [{ count }]: { count: string }[] = await this.ds.query(
      `SELECT count(*) FROM claims WHERE ($1::text IS NULL OR status::text = $1)`,
      [dto.status ?? null],
    );

    const planIds = [...new Set(rows.map((row) => row.planId))];
    const stockRows: { planId: string; availableStock: string }[] = planIds.length
      ? await this.ds.query(
          `SELECT "planId", count(*) AS "availableStock"
             FROM license_items
            WHERE status = 'AVAILABLE' AND "planId" = ANY($1::uuid[])
            GROUP BY "planId"`,
          [planIds],
        )
      : [];
    const stockByPlan = new Map(
      stockRows.map((row) => [row.planId, Number(row.availableStock)]),
    );

    const items = rows.map((row) =>
      AdminClaimResponseDto.from(row, stockByPlan.get(row.planId) ?? 0),
    );
    return PaginatedResponseDto.from(items, Number(count), dto.page, dto.pageSize);
  }

  /** RF-ADM-31: entrega reemplazo. D26: sin stock, el pedido queda en espera (409, el reclamo sigue OPEN). */
  async replace(
    admin: AuthenticatedUser,
    claimId: string,
  ): Promise<AdminClaimActionResponseDto> {
    const rows: { result: string | null }[] = await this.ds.query(
      `SELECT fn_resolve_claim($1, $2) AS result`,
      [claimId, admin.id],
    );
    const outcome = rows[0]?.result ?? null;
    if (outcome === null) {
      throw new NotFoundException('Reclamo no encontrado');
    }
    if (outcome === 'NO_STOCK') {
      throw new ConflictException(
        'Sin stock para reponer; el pedido queda en espera del próximo lote',
      );
    }

    const claim = await this.findClaimOrderNumber(claimId);
    await this.ds.transaction(async (m) => {
      await this.audit.log(m, {
        actorId: admin.id,
        action: 'claim.resolved',
        entity: 'claim',
        entityId: claimId,
        meta: { orderId: claim.orderId },
      });
    });
    return { claimId, status: ClaimStatus.RESOLVED, orderNumber: claim.orderNumber };
  }

  /** RF-ADM-32. */
  async reject(
    admin: AuthenticatedUser,
    claimId: string,
    dto: RejectClaimDto,
  ): Promise<AdminClaimActionResponseDto> {
    const claim = await this.findClaimOrderNumber(claimId);
    await this.ds.query(`SELECT fn_reject_claim($1, $2, $3)`, [
      claimId,
      admin.id,
      dto.reason,
    ]);

    await this.ds.transaction(async (m) => {
      await this.audit.log(m, {
        actorId: admin.id,
        action: 'claim.rejected',
        entity: 'claim',
        entityId: claimId,
        meta: { orderId: claim.orderId, reason: dto.reason },
      });
    });
    return { claimId, status: ClaimStatus.REJECTED, orderNumber: claim.orderNumber };
  }

  private async findClaimOrderNumber(
    claimId: string,
  ): Promise<{ orderId: string; orderNumber: number }> {
    const rows: { orderId: string; orderNumber: number }[] = await this.ds.query(
      `SELECT c."orderId", o."orderNumber" FROM claims c
         JOIN orders o ON o.id = c."orderId"
        WHERE c.id = $1`,
      [claimId],
    );
    const row = rows[0];
    if (!row) {
      throw new NotFoundException('Reclamo no encontrado');
    }
    return row;
  }
}

"use server";

import { auth } from "@/auth";

const API_URL = process.env.API_URL ?? "http://localhost:3000";

export type ClaimStatusView = "OPEN" | "RESOLVED" | "REJECTED";

export interface ClaimView {
  id: string;
  orderId: string;
  orderNumber: number;
  status: ClaimStatusView;
  reason: string;
  rejectionReason: string | null;
  createdAt: string;
  resolvedAt: string | null;
}

export interface PaginatedClaims {
  items: ClaimView[];
  total: number;
  page: number;
  pageSize: number;
}

export type ClaimsActionResult<T> =
  | { ok: true; data: T }
  | { ok: false; status: number; message: string };

async function callBackend<T>(
  path: string,
  init: { method: "GET" | "POST"; body?: unknown },
): Promise<ClaimsActionResult<T>> {
  const session = await auth();
  if (!session?.accessToken) {
    return { ok: false, status: 401, message: "Inicia sesión para continuar" };
  }

  const res = await fetch(`${API_URL}${path}`, {
    method: init.method,
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${session.accessToken}`,
    },
    body: init.body ? JSON.stringify(init.body) : undefined,
    cache: "no-store",
  });

  if (!res.ok) {
    const body = (await res.json().catch(() => null)) as { message?: string | string[] } | null;
    const message = Array.isArray(body?.message)
      ? body.message.join(", ")
      : body?.message ?? "No pudimos completar la operación";
    return { ok: false, status: res.status, message };
  }

  const data = (await res.json()) as T;
  return { ok: true, data };
}

export async function createClaim(
  orderId: string,
  orderItemId: string,
  reason: string,
): Promise<ClaimsActionResult<ClaimView>> {
  return callBackend<ClaimView>("/claims", {
    method: "POST",
    body: { orderId, orderItemId, reason },
  });
}

export async function listClaims(): Promise<ClaimsActionResult<PaginatedClaims>> {
  return callBackend<PaginatedClaims>("/claims?pageSize=50", { method: "GET" });
}

"use server";

import { auth } from "@/auth";

const API_URL = process.env.API_URL ?? "http://localhost:3000";

export type AdminClaimStatus = "OPEN" | "RESOLVED" | "REJECTED";

export interface AdminClaimView {
  claimId: string;
  orderId: string;
  orderNumber: number;
  status: AdminClaimStatus;
  reason: string;
  productName: string;
  planName: string;
  availableStock: number;
  createdAt: string;
  customerName: string | null;
  customerEmail: string;
}

export interface AdminClaimsPage {
  items: AdminClaimView[];
  total: number;
  page: number;
  pageSize: number;
}

export interface AdminClaimActionResult {
  claimId: string;
  status: AdminClaimStatus;
  orderNumber: number;
}

export type AdminClaimsActionResult<T> =
  | { ok: true; data: T }
  | { ok: false; status: number; message: string };

async function callBackend<T>(
  path: string,
  init: { method: "GET" | "POST"; body?: unknown },
): Promise<AdminClaimsActionResult<T>> {
  const session = await auth();
  if (!session?.accessToken) {
    return { ok: false, status: 401, message: "Inicia sesión para continuar" };
  }

  const res = await fetch(`${API_URL}${path}`, {
    method: init.method,
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${session.accessToken}`,
    },
    body: init.body ? JSON.stringify(init.body) : undefined,
    cache: "no-store",
  });

  if (!res.ok) {
    const body = (await res.json().catch(() => null)) as { message?: string | string[] } | null;
    const message = Array.isArray(body?.message)
      ? body.message.join(", ")
      : body?.message ?? "No pudimos completar la operación";
    return { ok: false, status: res.status, message };
  }

  const data = (await res.json()) as T;
  return { ok: true, data };
}

export async function fetchAdminClaims(
  status: AdminClaimStatus = "OPEN",
  pageSize = 50,
): Promise<AdminClaimsActionResult<AdminClaimsPage>> {
  return callBackend<AdminClaimsPage>(`/admin/claims?status=${status}&pageSize=${pageSize}`, {
    method: "GET",
  });
}

export async function replaceClaim(
  claimId: string,
): Promise<AdminClaimsActionResult<AdminClaimActionResult>> {
  return callBackend<AdminClaimActionResult>(`/admin/claims/${claimId}/replace`, { method: "POST" });
}

export async function rejectClaim(
  claimId: string,
  reason: string,
): Promise<AdminClaimsActionResult<AdminClaimActionResult>> {
  return callBackend<AdminClaimActionResult>(`/admin/claims/${claimId}/reject`, {
    method: "POST",
    body: { reason },
  });
}

Crea `frontend/src/components/admin-claims-queue.tsx`:

```tsx
"use client";

import { useState } from "react";
import { AdminClaimDetail } from "@/components/admin-claim-detail";
import { fetchAdminClaims, rejectClaim, replaceClaim, type AdminClaimView } from "@/lib/claims-admin-client";

function hoursAgo(iso: string): number {
  return Math.max(0, Math.round((Date.now() - new Date(iso).getTime()) / 3_600_000));
}

export function AdminClaimsQueue({ initialClaims }: { initialClaims: AdminClaimView[] }) {
  const [claims, setClaims] = useState(initialClaims);
  const [selectedId, setSelectedId] = useState<string | null>(initialClaims[0]?.claimId ?? null);
  const [rejecting, setRejecting] = useState(false);
  const [message, setMessage] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [submitting, setSubmitting] = useState(false);

  const selected = claims.find((c) => c.claimId === selectedId) ?? null;

  function selectClaim(claimId: string) {
    setSelectedId(claimId);
    setRejecting(false);
    setError(null);
  }

  async function refetchQueue(): Promise<AdminClaimView[]> {
    const result = await fetchAdminClaims("OPEN");
    if (!result.ok) {
      setError(result.message);
      return claims;
    }
    setClaims(result.data.items);
    return result.data.items;
  }

  async function handleReplace() {
    if (!selected) return;
    setSubmitting(true);
    setError(null);
    const result = await replaceClaim(selected.claimId);
    setSubmitting(false);
    if (!result.ok) {
      setError(result.message);
      await refetchQueue();
      return;
    }
    const fresh = await refetchQueue();
    setSelectedId(fresh[0]?.claimId ?? null);
    setRejecting(false);
    setMessage(`Pedido #${result.data.orderNumber}: reemplazo entregado.`);
  }

  async function handleConfirmReject(reason: string) {
    if (!selected) return;
    setSubmitting(true);
    setError(null);
    const result = await rejectClaim(selected.claimId, reason);
    setSubmitting(false);
    if (!result.ok) {
      setError(result.message);
      await refetchQueue();
      return;
    }
    const fresh = await refetchQueue();
    setSelectedId(fresh[0]?.claimId ?? null);
    setRejecting(false);
    setMessage(`Pedido #${result.data.orderNumber}: reclamo rechazado.`);
  }

  return (
    <div className="flex flex-col gap-4">
      {message ? <div className="rounded-[10px] bg-success-bg px-4 py-3 font-medium text-success-ink">{message}</div> : null}
      {error ? <div className="rounded-[10px] bg-danger-bg px-4 py-3 font-medium text-danger-ink">{error}</div> : null}
      {claims.length === 0 ? (
        <div className="rounded-2xl border border-line-soft bg-surface p-14 text-center">
          <p className="font-display text-xl font-bold text-ink">Sin reclamos abiertos</p>
          <p className="mt-1 text-muted">Cuando un cliente reporte una clave inválida, aparecerá aquí.</p>
        </div>
      ) : (
        <>
          <p className="text-muted">{claims.length} abiertos</p>
          <div className="flex flex-wrap items-start gap-5">
            <section aria-label="Cola de reclamos" className="flex w-full max-w-[360px] flex-col gap-2">
              {claims.map((c) => {
                const active = c.claimId === selectedId;
                return (
                  <button
                    key={c.claimId}
                    type="button"
                    aria-pressed={active}
                    onClick={() => selectClaim(c.claimId)}
                    className={`flex flex-col gap-1 rounded-xl border-2 px-4 py-3 text-left ${
                      active ? "border-accent bg-accent-soft-bg" : "border-line-soft bg-surface"
                    }`}
                  >
                    <span className="font-semibold text-ink">{c.customerName ?? c.customerEmail}</span>
                    <span className="text-sm text-muted">
                      {c.productName} · {c.planName}
                    </span>
                    <span className="text-sm text-muted">Reportado hace {hoursAgo(c.createdAt)} h</span>
                  </button>
                );
              })}
            </section>
            {selected ? (
              <AdminClaimDetail
                key={selected.claimId}
                claim={selected}
                rejecting={rejecting}
                submitting={submitting}
                onReplace={handleReplace}
                onStartReject={() => setRejecting(true)}
                onCancelReject={() => setRejecting(false)}
                onConfirmReject={handleConfirmReject}
              />
            ) : null}
          </div>
        </>
      )}
    </div>
  );
}
```
