# Reclamos y reposición de licencia (S8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dar al cliente una forma de reportar que una clave entregada no funciona y pedir reposición, y al admin una cola real en `/admin/reclamos` para resolverlo (entregar reemplazo o rechazar), cerrando el paso 7 del roadmap.

**Architecture:** Backend: módulo nuevo `claims/` (mismo patrón que `inventory/` y `orders/admin-payments*`) con dos controllers (`/claims` para el cliente, `/admin/claims` para el admin) sobre dos services separados. La tabla `claims` y sus índices ya existen desde Fundaciones; se agrega solo la columna `rejectionReason` (migración generada) y dos funciones Postgres (`fn_resolve_claim`, `fn_reject_claim`, mismo patrón que `fn_approve_payment`/`fn_reject_payment`) para la parte que debe ser atómica (D57): buscar stock con `SKIP LOCKED` y mover 3 filas (licencia original, licencia nueva, reclamo) junto. La creación del reclamo (validaciones de ventana/duplicado) vive en TypeScript dentro de una transacción con `SELECT ... FOR UPDATE` sobre el pedido — no necesita función SQL porque es una sola inserción, no una secuencia de updates. Frontend: se extiende `OrdersScreen` (ya existe de S4) con un bloque de "Reportar un problema"/estado del reclamo, y se construye `/admin/reclamos` copiando la estructura de `admin-payments-queue.tsx`/`admin-payment-detail.tsx` (cola + detalle + auto-avance).

**Tech Stack:** NestJS + TypeORM + Postgres (backend, 1 migración nueva); Next.js 16 App Router + TypeScript + Tailwind v4, Server Actions, Vitest (frontend). Sin BullMQ/colas nuevas (RF-NOT-05 queda fuera).

**Spec:** `docs/superpowers/specs/2026-11-13-reclamos-s8-design.md`

## Global Constraints

- Alcance solo RF-REC-01..05 + RF-ADM-30..32 + auditoría. **Fuera de este plan**: RF-REC-06 (reembolso manual,
  D27), RF-NOT-05 (correo al resolver), RF-PED-06 (guía "cómo activar").
- Ventana de reposición: **7 días** desde `orders.updatedAt` (proxy de entrega ya usado por
  `OrderResponseDto.tracking.deliveredAt` desde S4; no se agrega columna `deliveredAt`).
- Máximo **1 reposición por pedido** (D26): bloquear nueva creación si el pedido ya tiene un reclamo `OPEN` o
  `RESOLVED` (no `REJECTED` — eso no cuenta como reposición usada).
- El cliente elige la licencia reclamada vía `orderItemId` (no `licenseItemId`, interno); si el pedido tiene una
  sola licencia, el frontend la autoselecciona sin mostrar el campo.
- El admin **nunca** ve la clave en claro en la cola de reclamos — siempre enmascarada, sin acción de revelar.
- Motivo de rechazo del admin: texto libre (`@IsString() @Length(3, 500)`), no catálogo fijo como en pagos.
- Dinero/stock/estado: toda la lógica de `fn_resolve_claim`/`fn_reject_claim` se prueba con Postgres/Redis
  reales (`backend/test/*.e2e-spec.ts`), nunca con mocks.
- Toda mutación crítica (crear reclamo, entregar reemplazo, rechazar) escribe `audit_logs` en la misma
  transacción (regla 6): `claim.created`, `claim.resolved`, `claim.rejected`.
- Entidades/rutas/código en inglés; mensajes al usuario y documentación en español.
- Accesibilidad AA: botones ≥44px de alto, el color nunca es el único indicador.
- Nunca editar una migración ya aplicada (`InitialSchema`, `DatabaseLogic`, etc.) — todo cambio de esquema va en
  la migración nueva de este plan.

Abrir el archivo generado. **No tocar** la línea `ALTER TABLE ... ADD "rejectionReason" ...` que ya está dentro
de `up()` ni la línea `DROP COLUMN` que ya está dentro de `down()` — tal cual las dejó el comando. Agregar

```ts
    // RF-ADM-31/D26/D28: repone con una licencia AVAILABLE del mismo plan (SKIP LOCKED); sin stock no toca
    // nada y el reclamo sigue OPEN. La original va a VOID conservando su orderItemId histórico; la nueva
    // toma ese MISMO orderItemId, así POST /orders/:id/license/reveal (ya existe desde S4) la encuentra sin
    // ningún cambio ahí.
    await queryRunner.query(`
      CREATE OR REPLACE FUNCTION fn_resolve_claim(p_claim_id uuid, p_admin_id uuid)
      RETURNS text LANGUAGE plpgsql AS $$
      DECLARE
        v_claim claims%ROWTYPE;
        v_plan_id uuid;
        v_order_item_id uuid;
        v_new_license_id uuid;
      BEGIN
        SELECT * INTO v_claim FROM claims WHERE id = p_claim_id FOR UPDATE;
        IF NOT FOUND THEN
          RETURN NULL;
        END IF;
        IF v_claim.status <> 'OPEN' THEN
          RAISE EXCEPTION 'El reclamo ya fue resuelto' USING ERRCODE = 'P0001';
        END IF;

        SELECT "planId", "orderItemId" INTO v_plan_id, v_order_item_id
          FROM license_items WHERE id = v_claim."licenseItemId";

        SELECT id INTO v_new_license_id
          FROM license_items
         WHERE "planId" = v_plan_id AND status = 'AVAILABLE'
         ORDER BY "createdAt"
         LIMIT 1
         FOR UPDATE SKIP LOCKED;

        IF v_new_license_id IS NULL THEN
          RETURN 'NO_STOCK';
        END IF;

        UPDATE license_items SET status = 'VOID' WHERE id = v_claim."licenseItemId";
        UPDATE license_items
           SET status = 'SOLD', "orderItemId" = v_order_item_id,
               "replacesId" = v_claim."licenseItemId", "soldAt" = now()
         WHERE id = v_new_license_id;

        UPDATE claims
           SET status = 'RESOLVED', "replacementLicenseId" = v_new_license_id,
               "resolvedById" = p_admin_id, "resolvedAt" = now()
         WHERE id = p_claim_id;

        RETURN 'RESOLVED';
      END $$;
    `);

    await queryRunner.query(`
      CREATE OR REPLACE FUNCTION fn_reject_claim(p_claim_id uuid, p_admin_id uuid, p_reason text)
      RETURNS boolean LANGUAGE plpgsql AS $$
      DECLARE
        v_claim claims%ROWTYPE;
      BEGIN
        SELECT * INTO v_claim FROM claims WHERE id = p_claim_id FOR UPDATE;
        IF NOT FOUND THEN
          RETURN false;
        END IF;
        IF v_claim.status <> 'OPEN' THEN
          RAISE EXCEPTION 'El reclamo ya fue resuelto' USING ERRCODE = 'P0001';
        END IF;

        UPDATE claims SET status = 'REJECTED', "rejectionReason" = p_reason,
          "resolvedById" = p_admin_id, "resolvedAt" = now()
         WHERE id = p_claim_id;
        RETURN true;
      END $$;
    `);
```

Esas dos llamadas van justo antes del `}` que cierra `up()` (el que ya estaba generado).

Dentro de `down()`, agregar estas dos llamadas **antes** de la línea `DROP COLUMN` que ya está (hay que borrar
las funciones antes de poder borrar la columna que usan, aunque Postgres no obliga el orden aquí — es solo
para que `down()` quede simétrico a `up()` en orden inverso):

```ts
    await queryRunner.query(`DROP FUNCTION IF EXISTS fn_reject_claim(uuid, uuid, text)`);
    await queryRunner.query(`DROP FUNCTION IF EXISTS fn_resolve_claim(uuid, uuid)`);
```

```ts
import {
  ConflictException,
  ForbiddenException,
  Injectable,
  NotFoundException,
} from '@nestjs/common';
import { DataSource } from 'typeorm';
import { AuditService } from '../audit/audit.service';
import { PaginatedResponseDto } from '../common/dto/paginated-response.dto';
import type { AuthenticatedUser } from '../common/types/authenticated-user';
import { ClaimStatus, OrderStatus } from '../database/enums';
import { ClaimResponseDto } from './dto/claim-response.dto';
import { CreateClaimDto } from './dto/create-claim.dto';
import { ListClaimsQueryDto } from './dto/list-claims-query.dto';

const REPLACEMENT_WINDOW_MS = 7 * 24 * 60 * 60 * 1000;

interface ClaimRow {
  id: string;
  orderId: string;
  orderNumber: number;
  status: ClaimStatus;
  reason: string;
  rejectionReason: string | null;
  createdAt: Date;
  resolvedAt: Date | null;
}

@Injectable()
export class ClaimsService {
  constructor(
    private readonly ds: DataSource,
    private readonly audit: AuditService,
  ) {}

  /** RF-REC-01..03: pedido entregado, dentro de la ventana de 7 días (D25), sin reclamo abierto ni
   * reposición ya usada (D26). El lock FOR UPDATE sobre el pedido serializa reclamos concurrentes. */
  async create(
    user: AuthenticatedUser,
    dto: CreateClaimDto,
  ): Promise<ClaimResponseDto> {
    const claimId = await this.ds.transaction(async (m) => {
      const orders: { id: string; status: OrderStatus; updatedAt: Date }[] =
        await m.query(
          `SELECT id, status, "updatedAt" FROM orders WHERE id = $1 AND "userId" = $2 FOR UPDATE`,
          [dto.orderId, user.id],
        );
      const order = orders[0];
      if (!order) {
        throw new NotFoundException('Pedido no encontrado');
      }
      if (order.status !== OrderStatus.DELIVERED) {
        throw new ForbiddenException('Solo puedes reclamar un pedido entregado');
      }
      if (Date.now() - order.updatedAt.getTime() > REPLACEMENT_WINDOW_MS) {
        throw new ConflictException('La ventana de reposición de 7 días ya venció');
      }

      const licenses: { id: string }[] = await m.query(
        `SELECT li.id FROM license_items li
           JOIN order_items oi ON oi.id = li."orderItemId"
          WHERE oi.id = $1 AND oi."orderId" = $2 AND li.status = 'SOLD'`,
        [dto.orderItemId, dto.orderId],
      );
      const license = licenses[0];
      if (!license) {
        throw new NotFoundException('La licencia indicada no es parte de este pedido');
      }

      const existing: { status: ClaimStatus }[] = await m.query(
        `SELECT status FROM claims WHERE "orderId" = $1 AND status IN ('OPEN', 'RESOLVED')`,
        [dto.orderId],
      );
      if (existing.some((c) => c.status === ClaimStatus.OPEN)) {
        throw new ConflictException('Ya hay un reclamo abierto para este pedido');
      }
      if (existing.some((c) => c.status === ClaimStatus.RESOLVED)) {
        throw new ConflictException('Este pedido ya usó su reposición');
      }

      const [{ id }]: { id: string }[] = await m.query(
        `INSERT INTO claims ("orderId", "licenseItemId", "userId", reason, status)
         VALUES ($1, $2, $3, $4, 'OPEN') RETURNING id`,
        [dto.orderId, license.id, user.id, dto.reason],
      );

      await this.audit.log(m, {
        actorId: user.id,
        action: 'claim.created',
        entity: 'claim',
        entityId: id,
        meta: { orderId: dto.orderId, orderItemId: dto.orderItemId },
      });
      return id;
    });

    return this.findOne(user.id, claimId);
  }

  async listForUser(
    userId: string,
    dto: ListClaimsQueryDto,
  ): Promise<PaginatedResponseDto<ClaimResponseDto>> {
    const offset = (dto.page - 1) * dto.pageSize;
    const rows: ClaimRow[] = await this.ds.query(
      `SELECT c.id, c."orderId", o."orderNumber", c.status, c.reason, c."rejectionReason",
              c."createdAt", c."resolvedAt"
         FROM claims c
         JOIN orders o ON o.id = c."orderId"
        WHERE c."userId" = $1
        ORDER BY c."createdAt" DESC
        LIMIT $2 OFFSET $3`,
      [userId, dto.pageSize, offset],
    );
    const [{ count }]: { count: string }[] = await this.ds.query(
      `SELECT count(*) FROM claims WHERE "userId" = $1`,
      [userId],
    );
    return PaginatedResponseDto.from(
      rows.map((row) => this.toResponse(row)),
      Number(count),
      dto.page,
      dto.pageSize,
    );
  }

  private async findOne(userId: string, claimId: string): Promise<ClaimResponseDto> {
    const rows: ClaimRow[] = await this.ds.query(
      `SELECT c.id, c."orderId", o."orderNumber", c.status, c.reason, c."rejectionReason",
              c."createdAt", c."resolvedAt"
         FROM claims c
         JOIN orders o ON o.id = c."orderId"
        WHERE c.id = $1 AND c."userId" = $2`,
      [claimId, userId],
    );
    return this.toResponse(rows[0]);
  }

  private toResponse(row: ClaimRow): ClaimResponseDto {
    return {
      id: row.id,
      orderId: row.orderId,
      orderNumber: row.orderNumber,
      status: row.status,
      reason: row.reason,
      rejectionReason: row.rejectionReason,
      createdAt: row.createdAt,
      resolvedAt: row.resolvedAt,
    };
  }
}
```

```ts
import { ConflictException, Injectable, NotFoundException } from '@nestjs/common';
import { DataSource } from 'typeorm';
import { AuditService } from '../audit/audit.service';
import { PaginatedResponseDto } from '../common/dto/paginated-response.dto';
import type { AuthenticatedUser } from '../common/types/authenticated-user';
import { ClaimStatus } from '../database/enums';
import {
  AdminClaimResponseDto,
  ClaimActionResultDto,
} from './dto/admin-claim-response.dto';
import { ListAdminClaimsQueryDto } from './dto/list-admin-claims-query.dto';
import { RejectClaimDto } from './dto/reject-claim.dto';

interface AdminClaimRow {
  claimId: string;
  orderId: string;
  orderNumber: number;
  status: ClaimStatus;
  reason: string;
  planId: string;
  productName: string;
  planName: string;
  createdAt: Date;
  customerName: string | null;
  customerEmail: string;
}

@Injectable()
export class AdminClaimsService {
  constructor(
    private readonly ds: DataSource,
    private readonly audit: AuditService,
  ) {}

  async list(
    dto: ListAdminClaimsQueryDto,
  ): Promise<PaginatedResponseDto<AdminClaimResponseDto>> {
    const offset = (dto.page - 1) * dto.pageSize;
    const rows: AdminClaimRow[] = await this.ds.query(
      `SELECT c.id AS "claimId", c."orderId", o."orderNumber", c.status, c.reason,
              pl.id AS "planId", pl.name AS "planName", pr.name AS "productName",
              c."createdAt", u.name AS "customerName", u.email AS "customerEmail"
         FROM claims c
         JOIN orders o ON o.id = c."orderId"
         JOIN users u ON u.id = c."userId"
         JOIN license_items li ON li.id = c."licenseItemId"
         JOIN plans pl ON pl.id = li."planId"
         JOIN products pr ON pr.id = pl."productId"
        WHERE ($1::text IS NULL OR c.status::text = $1)
        ORDER BY c."createdAt" ASC
        LIMIT $2 OFFSET $3`,
      [dto.status ?? null, dto.pageSize, offset],
    );
    const [{ count }]: { count: string }[] = await this.ds.query(
      `SELECT count(*) FROM claims WHERE ($1::text IS NULL OR status::text = $1)`,
      [dto.status ?? null],
    );

    const planIds = [...new Set(rows.map((row) => row.planId))];
    const stockRows: { planId: string; availableStock: string }[] = planIds.length
      ? await this.ds.query(
          `SELECT "planId", count(*) AS "availableStock"
             FROM license_items
            WHERE status = 'AVAILABLE' AND "planId" = ANY($1::uuid[])
            GROUP BY "planId"`,
          [planIds],
        )
      : [];
    const stockByPlan = new Map(stockRows.map((row) => [row.planId, Number(row.availableStock)]));

    const items = rows.map((row) => ({
      claimId: row.claimId,
      orderId: row.orderId,
      orderNumber: row.orderNumber,
      status: row.status,
      reason: row.reason,
      productName: row.productName,
      planName: row.planName,
      availableStock: stockByPlan.get(row.planId) ?? 0,
      createdAt: row.createdAt,
      customerName: row.customerName,
      customerEmail: row.customerEmail,
    }));
    return PaginatedResponseDto.from(items, Number(count), dto.page, dto.pageSize);
  }

  /** RF-ADM-31/D26/D28: repone con una licencia AVAILABLE del mismo plan; sin stock, sigue OPEN. */
  async replace(admin: AuthenticatedUser, claimId: string): Promise<ClaimActionResultDto> {
    const result = await this.ds.transaction(async (m) => {
      const rows: { result: string | null }[] = await m.query(
        `SELECT fn_resolve_claim($1, $2) AS result`,
        [claimId, admin.id],
      );
      const outcome = rows[0]?.result ?? null;
      if (outcome === 'RESOLVED') {
        await this.audit.log(m, {
          actorId: admin.id,
          action: 'claim.resolved',
          entity: 'claim',
          entityId: claimId,
        });
      }
      return outcome;
    });

    if (result === null) {
      throw new NotFoundException('Reclamo no encontrado');
    }
    if (result === 'NO_STOCK') {
      throw new ConflictException(
        'Sin stock para reponer; el pedido queda en espera del próximo lote',
      );
    }
    return this.actionResult(claimId);
  }

  /** RF-ADM-32: motivo libre, visible para el cliente en GET /claims. */
  async reject(
    admin: AuthenticatedUser,
    claimId: string,
    dto: RejectClaimDto,
  ): Promise<ClaimActionResultDto> {
    const rejected = await this.ds.transaction(async (m) => {
      const rows: { rejected: boolean }[] = await m.query(
        `SELECT fn_reject_claim($1, $2, $3) AS rejected`,
        [claimId, admin.id, dto.reason],
      );
      const ok = rows[0]?.rejected ?? false;
      if (ok) {
        await this.audit.log(m, {
          actorId: admin.id,
          action: 'claim.rejected',
          entity: 'claim',
          entityId: claimId,
          meta: { reason: dto.reason },
        });
      }
      return ok;
    });

    if (!rejected) {
      throw new NotFoundException('Reclamo no encontrado');
    }
    return this.actionResult(claimId);
  }

  private async actionResult(claimId: string): Promise<ClaimActionResultDto> {
    const rows: { claimId: string; status: ClaimStatus; orderNumber: number }[] =
      await this.ds.query(
        `SELECT c.id AS "claimId", c.status, o."orderNumber"
           FROM claims c JOIN orders o ON o.id = c."orderId"
          WHERE c.id = $1`,
        [claimId],
      );
    return rows[0];
  }
}
```

```ts
"use server";

import { auth } from "@/auth";

const API_URL = process.env.API_URL ?? "http://localhost:3000";

export type ClaimStatus = "OPEN" | "RESOLVED" | "REJECTED";

export interface ClaimView {
  id: string;
  orderId: string;
  orderNumber: number;
  status: ClaimStatus;
  reason: string;
  rejectionReason: string | null;
  createdAt: string;
  resolvedAt: string | null;
}

export interface PaginatedClaims {
  items: ClaimView[];
  total: number;
  page: number;
  pageSize: number;
}

export type ClaimsActionResult<T> =
  | { ok: true; data: T }
  | { ok: false; status: number; message: string };

async function callBackend<T>(
  path: string,
  init: { method: "GET" | "POST"; body?: unknown },
): Promise<ClaimsActionResult<T>> {
  const session = await auth();
  if (!session?.accessToken) {
    return { ok: false, status: 401, message: "Inicia sesión para continuar" };
  }

  const res = await fetch(`${API_URL}${path}`, {
    method: init.method,
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${session.accessToken}`,
    },
    body: init.body ? JSON.stringify(init.body) : undefined,
    cache: "no-store",
  });

  if (!res.ok) {
    const body = (await res.json().catch(() => null)) as { message?: string | string[] } | null;
    const message = Array.isArray(body?.message)
      ? body.message.join(", ")
      : body?.message ?? "No pudimos completar la operación";
    return { ok: false, status: res.status, message };
  }

  const data = (await res.json()) as T;
  return { ok: true, data };
}

export async function createClaim(
  orderId: string,
  orderItemId: string,
  reason: string,
): Promise<ClaimsActionResult<ClaimView>> {
  return callBackend<ClaimView>("/claims", {
    method: "POST",
    body: { orderId, orderItemId, reason },
  });
}

export async function listClaims(): Promise<ClaimsActionResult<PaginatedClaims>> {
  return callBackend<PaginatedClaims>("/claims?pageSize=50", { method: "GET" });
}
```

```ts
import { auth } from "@/auth";

const API_URL = process.env.API_URL ?? "http://localhost:3000";

export type AdminClaimStatus = "OPEN" | "RESOLVED" | "REJECTED";

export interface AdminClaimView {
  claimId: string;
  orderId: string;
  orderNumber: number;
  status: AdminClaimStatus;
  reason: string;
  productName: string;
  planName: string;
  availableStock: number;
  createdAt: string;
  customerName: string | null;
  customerEmail: string;
}

export interface AdminClaimsPage {
  items: AdminClaimView[];
  total: number;
  page: number;
  pageSize: number;
}

export interface ClaimActionResult {
  claimId: string;
  status: AdminClaimStatus;
  orderNumber: number;
}

export type AdminClaimsActionResult<T> =
  | { ok: true; data: T }
  | { ok: false; status: number; message: string };

async function callBackend<T>(
  path: string,
  init: { method: "GET" | "POST"; body?: unknown },
): Promise<AdminClaimsActionResult<T>> {
  const session = await auth();
  if (!session?.accessToken) {
    return { ok: false, status: 401, message: "Inicia sesión para continuar" };
  }

  const res = await fetch(`${API_URL}${path}`, {
    method: init.method,
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${session.accessToken}`,
    },
    body: init.body ? JSON.stringify(init.body) : undefined,
    cache: "no-store",
  });

  if (!res.ok) {
    const body = (await res.json().catch(() => null)) as { message?: string | string[] } | null;
    const message = Array.isArray(body?.message)
      ? body.message.join(", ")
      : body?.message ?? "No pudimos completar la operación";
    return { ok: false, status: res.status, message };
  }

  const data = (await res.json()) as T;
  return { ok: true, data };
}

export async function fetchAdminClaims(
  status: AdminClaimStatus = "OPEN",
  pageSize = 50,
): Promise<AdminClaimsActionResult<AdminClaimsPage>> {
  return callBackend<AdminClaimsPage>(`/admin/claims?status=${status}&pageSize=${pageSize}`, {
    method: "GET",
  });
}

export async function replaceClaim(claimId: string): Promise<AdminClaimsActionResult<ClaimActionResult>> {
  return callBackend<ClaimActionResult>(`/admin/claims/${claimId}/replace`, { method: "POST" });
}

export async function rejectClaim(
  claimId: string,
  reason: string,
): Promise<AdminClaimsActionResult<ClaimActionResult>> {
  return callBackend<ClaimActionResult>(`/admin/claims/${claimId}/reject`, {
    method: "POST",
    body: { reason },
  });
}
```

```tsx
      return claims;
    }
    setClaims(result.data.items);
    return result.data.items;
  }

  async function handleReplace() {
    if (!selected) return;
    setSubmitting(true);
    setError(null);
    const result = await replaceClaim(selected.claimId);
    setSubmitting(false);
    if (!result.ok) {
      setError(result.message);
      await refetchQueue();
      return;
    }
    const fresh = await refetchQueue();
    setSelectedId(fresh[0]?.claimId ?? null);
    setRejecting(false);
    setReason("");
    setMessage(`Reclamo del pedido #${result.data.orderNumber} resuelto. Reemplazo entregado.`);
  }

  async function handleConfirmReject() {
    if (!selected || reason.trim().length < 3) return;
    setSubmitting(true);
    setError(null);
    const result = await rejectClaim(selected.claimId, reason.trim());
    setSubmitting(false);
    if (!result.ok) {
      setError(result.message);
      await refetchQueue();
      return;
    }
    const fresh = await refetchQueue();
    setSelectedId(fresh[0]?.claimId ?? null);
    setRejecting(false);
    setReason("");
    setMessage(`Reclamo del pedido #${result.data.orderNumber} rechazado.`);
  }

  return (
    <div className="flex flex-col gap-4">
      {message ? (
        <div className="rounded-[10px] bg-success-bg px-4 py-3 font-medium text-success-ink">{message}</div>
      ) : null}
      {error ? (
        <div className="rounded-[10px] bg-danger-bg px-4 py-3 font-medium text-danger-ink">{error}</div>
      ) : null}
      {claims.length === 0 ? (
        <div className="rounded-2xl border border-line-soft bg-surface p-14 text-center">
          <p className="font-display text-xl font-bold text-ink">Sin reclamos abiertos</p>
          <p className="mt-1 text-muted">Cuando un cliente reporte una clave inválida, aparecerá aquí.</p>
        </div>
      ) : (
        <>
          <p className="text-muted">{claims.length} abiertos</p>
          <div className="flex flex-wrap items-start gap-5">
            <section aria-label="Cola de reclamos" className="flex w-full max-w-[360px] flex-col gap-2">
              {claims.map((c) => {
                const active = c.claimId === selectedId;
                return (
                  <button
                    key={c.claimId}
                    type="button"
                    aria-pressed={active}
                    onClick={() => selectClaim(c.claimId)}
                    className={`flex flex-col gap-1 rounded-xl border-2 px-4 py-3 text-left ${
                      active ? "border-accent bg-accent-soft-bg" : "border-line-soft bg-surface"
                    }`}
                  >
                    <span className="font-semibold text-ink">{c.customerName ?? c.customerEmail}</span>
                    <span className="text-sm text-muted">
                      {c.productName} · {c.planName}
                    </span>
                    <span className="text-sm text-muted">Pedido #{c.orderNumber}</span>
                  </button>
                );
              })}
            </section>
            {selected ? (
              <AdminClaimDetail
                key={selected.claimId}
                claim={selected}
                rejecting={rejecting}
                reason={reason}
                submitting={submitting}
                onReplace={handleReplace}
                onStartReject={() => setRejecting(true)}
                onCancelReject={() => {
                  setRejecting(false);
                  setReason("");
                }}
                onReasonChange={setReason}
                onConfirmReject={handleConfirmReject}
              />
            ) : null}
          </div>
        </>
      )}
    </div>
  );
}
```
